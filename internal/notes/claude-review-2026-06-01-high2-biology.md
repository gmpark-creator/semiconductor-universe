## 검토 차원과 결과

1. **과학 정확성 — PASS.** 표본 확인:
   - 생명 구성 단계(세포→조직→기관→개체→개체군→군집→생태계), 세포막 선택적 투과성, 물질대사(동화·이화), 효소(생체 촉매·활성화 에너지) ✓
   - 세포 호흡·ATP, 생산자·소비자·분해자, 에너지 흐름(한 방향)·물질 순환, 환경 저항 ✓
   - 뉴런·막전위·활동 전위·역치, 실무율(자극 강하면 빈도↑), 도약전도 ✓
   - 시냅스·신경전달물질, 중추/말초 신경계, 반사 ✓
   - 항상성, 인슐린/글루카곤(이자), 음성 피드백 ✓
   - 선천/후천 면역, B/T 림프구, 항체, 기억 세포, 백신 ✓
   - DNA·유전자·염색체, 유전정보 흐름(DNA→RNA→단백질) ✓
   - 체세포/감수분열(염색체 수 절반), 상동염색체·교차, 유전적 다양성 ✓
   - 유전자형/표현형(환경 영향 명시), 대립유전자, **"우열로 항상 단순 설명 안 됨" 신중한 보충** ✓
   - 진화(집단 유전자 빈도 변화), 자연선택, 유전적 부동, 계통수(형태+DNA 서열) ✓

2. **도해-본문 일치 — PASS.** 3종 모두 핵심을 정확히 도식화(구성 단계+물질대사/ATP / 신경·내분비·면역 / DNA·감수분열·계통수·진화).
